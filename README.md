# 📊 Parks & Rec Workforce & Payroll Analytics Dashboard

## 📌 Project Overview
An exploratory data analysis project examining municipal workforce payroll, departmental expenditures, and employee salary distributions. The objective was to clean raw public sector data, normalize records, and build executive-level visual dashboards to track payroll trends.

---

## 🛠️ Tech Stack & Tools Used
* **Python (Pandas, NumPy):** Data cleaning, missing value handling, grouping, and statistical aggregation.
* **SQL (MySQL):** Querying relational workforce tables and filtering department-specific metrics.
* **Microsoft Excel:** Executive dashboarding utilizing PivotTables and PivotCharts.

---

## 🔍 Key Insights & Findings
* **Salary Distribution:** Identified key cost centers and salary variance across municipal departments.
* **Headcount Analysis:** Mapped departmental staffing levels and total payroll allocation to support budget review.
